# BulkPublish MCP Server

Approval-first social content adaptation, scheduling, and publishing through
the BulkPublish API and remote MCP server.

**Source:** [github.com/azeemkafridi/bulkpublish-api](https://github.com/azeemkafridi/bulkpublish-api)

## Installation

Configure the remote MCP endpoint:

```text
https://mcp.bulkpublish.com/mcp
```

See the [BulkPublish API documentation](https://app.bulkpublish.com/docs) for
authentication and tool details.

## Related skills

The reusable [BulkPublish social media content skills](https://github.com/azeemkafridi/bulkpublish-api/tree/main/skills/social-media-content-skills)
cover planning, platform adaptation, review, scheduling, and publishing.
