# Statsnet MCP Server

Community remote MCP for worldwide company background checks — registration, executives, courts, and finances.

**Source:** [github.com/usenetstate/statsnet-mcp](https://github.com/usenetstate/statsnet-mcp)

**Remote endpoint:** `https://statsnet.co/mcp`  
**Official Registry:** `io.github.usenetstate/statsnet`  
**Website:** https://statsnet.co

## Installation

Connect any MCP client to the remote endpoint (no local install required):

```
https://statsnet.co/mcp
```

## Use Case

Background-check any company in the world from an AI assistant — registration details, executives, government contracts, courts, and finances.
